# 可运行的 Go / TypeScript MCP Server 生成

`POST /api/wrapper/skeleton` 接收 `spec`、`lang` 和可选的 `base_url`，返回 `lang`、兼容原接口的 `code`、项目文件 `files` 和运行命令 `run`。语言支持 `go` / `golang`、`ts` / `typescript`，省略时默认 Go；其他语言返回 400。

| 输出 | 项目文件 | 编译与启动 |
| --- | --- | --- |
| Go | main.go、go.mod | go build .；go run . |
| TypeScript | server.ts、package.json、tsconfig.json | npm install；npm run build；npm start |

Go 输出使用标准库，无需引用本网关的内部包。TypeScript 输出使用 Node.js HTTP 与 fetch，要求 Node.js 22 或更新版本，项目附带 TypeScript 编译依赖。

## 生成并保存项目

在项目根目录使用 PowerShell 7：

```powershell
$login = Invoke-RestMethod 'http://localhost:8080/api/auth/login' -Method Post -ContentType 'application/json' -Body '{"username":"admin","password":"admin123"}'
$spec = Get-Content -Raw 'specs/weather-v1.json' | ConvertFrom-Json
$payload = @{spec=$spec; lang='go'; base_url='http://localhost:9002'} | ConvertTo-Json -Depth 50
$project = Invoke-RestMethod 'http://localhost:8080/api/wrapper/skeleton' -Method Post -ContentType 'application/json' -Headers @{Authorization="Bearer $($login.token)"} -Body $payload
$output = Join-Path $PWD 'generated-go'
New-Item -ItemType Directory -Path $output -Force | Out-Null
foreach ($file in $project.files.PSObject.Properties) {
    Set-Content -LiteralPath (Join-Path $output $file.Name) -Value $file.Value -Encoding utf8
}
Set-Location $output
go run .
```

TypeScript 项目使用 `lang='ts'`，保存至另一目录，然后执行 `npm install`、`npm run build`、`npm start`。

## 运行配置与接口

| 环境变量 | 用途 |
| --- | --- |
| REST_BASE_URL | 覆盖全部 REST 服务地址；默认使用 base_url 或 OpenAPI 各级 servers |
| HOST | 监听地址，默认 127.0.0.1 |
| PORT | 监听端口，默认 8081 |
| MCP_BEARER_TOKEN | 配置后，/mcp 需要对应的 Bearer 令牌 |
| REST_BEARER_TOKEN | 转发至 REST 服务的 Bearer 令牌 |

服务提供 `GET /health` 和 `POST /mcp`，支持 `initialize`、`ping`、`tools/list`、`tools/call` 和无响应体的通知。沿用网关协议版本 `2025-03-26`，采用无会话的 JSON 响应，不提供独立 SSE 流，`GET /mcp` 返回 405；设计依据是 [MCP 对 JSON 响应及 GET 405 的定义](https://modelcontextprotocol.io/specification/2025-03-26/basic/transports)。此模板处理单条 JSON-RPC 消息。

```powershell
$headers = @{Accept='application/json, text/event-stream'}
Invoke-RestMethod 'http://localhost:8081/mcp' -Method Post -ContentType 'application/json' -Headers $headers -Body '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"verification","version":"1.0.0"}}}'
Invoke-RestMethod 'http://localhost:8081/mcp' -Method Post -ContentType 'application/json' -Headers $headers -Body '{"jsonrpc":"2.0","id":2,"method":"tools/list"}'
Invoke-RestMethod 'http://localhost:8081/mcp' -Method Post -ContentType 'application/json' -Headers $headers -Body '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"weather_current","arguments":{"city":"Shanghai"}}}'
```

生成器覆盖 GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS、本地与递归 Schema 引用、公共参数、请求头/cookie、数组查询参数、JSON/表单/文本请求体与上游 Bearer/API Key 认证。详细参数格式及支持边界见 `OpenAPI兼容性与验证.md`。下游 HTTP 错误转换为 MCP `isError`。

## 自动验收

```powershell
docker compose up --build -d gateway
node tools/verify-skeletons.mjs
```

脚本从真实生成接口获取两个项目（Go 使用 JSON、TS 使用 YAML 输入），在临时目录执行 Go 编译与 TypeScript 安装/编译，并实际启动它们。它验证本地引用、公共参数、查询数组/deepObject、请求头/cookie、JSON/表单/文本请求体、安全方案组合、HEAD/OPTIONS、traceparent 透传、HTTP 503 和协议错误。还验证 Docker 网关真实导入、REST/MCP 调用、凭据摘要隐藏，并重启网关检查映射恢复。

测试结束后停止临时服务，删除临时目录，并按精确 server ID / trace ID 清理本次注册、映射和调用审计记录。项目原有数据保持保留。支持通过 `GATEWAY_URL`、`MCP_USERNAME`、`MCP_PASSWORD` 环境变量配置验证连接。
