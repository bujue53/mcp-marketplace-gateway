# 性能验收报告

验收开始时间：2026-10-15 01:35:33（Asia/Shanghai）。机器原始结果：最终三项验收结果.json。

## 环境与方法

- Docker Desktop Linux 容器，16 个 CPU，内存约 7.37 GiB；所有服务运行在同一 Docker 网络。
- 原生 Go MCP 下游，JWT/RBAC、Redis 令牌桶、熔断、100% OpenTelemetry 追踪、成本与业务审计保持启用。
- 单用户限流额度为 5000 RPS，关闭控制台逐请求文本日志；正常业务配置仍为 20 RPS。
- 元数据缓存 500ms；权限覆盖逐次查询 PostgreSQL，验证即时撤销。
- 固定发送 2100 RPS，持续 20 秒，并发工作线程 128 个；预热 100 次。
- 成功要求 HTTP 200、JSON-RPC 2.0、无协议错误且工具没有返回 isError。

## 优化过程

第一轮约 1910.9 成功 QPS、网关开销 P99 25.80ms，发生下游短连接端口耗尽。共享并扩大连接池、减少热路径统计查询、加入有边界的元数据缓存与批量日志写入后，通过完整复验，最终数字见上表。
