# 部署文档

## 1. 前置要求

- Docker Desktop（含 Docker Compose v2）；
- 推荐内存 ≥ 4GB；
- 端口 `8080 / 5173 / 5432 / 6379 / 16686 / 9090` 空闲。

## 2. 服务组件

| 服务 | 镜像/来源 | 端口 | 说明 |
| --- | --- | --- | --- |
| `gateway` | 本地构建（Go） | 8080 | 注册中心 + 网关 + MCP + 包装器 |
| `web` | 本地构建（React） | 5173 | 工具市场前端 |
| `postgres` | postgres:16-alpine | 5432 | 元数据 / 审计 |
| `redis` | redis:7-alpine | 6379 | 限流 / 熔断 |
| `jaeger` | jaegertracing/all-in-one | 16686 | 全链路追踪 |
| `prometheus` | prom/prometheus | 9090 | 指标采集 |
| `legacy-api` | 本地构建（Python） | 9002 | 遗留 REST 天气服务（OpenAPI 源） |
| `mock-mcp` | 本地构建（Python） | 9003 | 原生 MCP 示例服务 |

## 3. 一键部署

在仓库根目录执行：

```bash
cp .env.example .env          # 建议修改 JWT_SECRET 与数据库密码
docker compose up --build -d
docker compose ps             # 等待 gateway 变为 healthy / running
```

网关启动时会自动执行数据库迁移，并按 `SEED_ON_STARTUP=true` 注册示例服务并自动包装 OpenAPI 工具（首次可能需要几十秒拉取依赖）。

## 4. 访问入口

| 用途 | 地址 |
| --- | --- |
| 工具市场前端 | http://localhost:5173 |
| 网关 API 根 | http://localhost:8080 |
| 网关健康检查 | http://localhost:8080/health |
| Prometheus 指标 | http://localhost:8080/metrics |
| Jaeger UI | http://localhost:16686 |

## 5. 登录

默认管理员：`admin / admin123`；开发者：`dev / dev123`。前端登录后即可一键接入工具、查看统计。

## 6. 端到端演示（Agent 调用自动包装工具）

```bash
# 在本机跑客户端（需 Python 3）
python agents/mcp_client.py --list
# 通过 MCP /mcp 调用自动生成的天气工具
python agents/mcp_client.py --mcp --tool weather_current --args '{"city":"东莞"}'
# 通过 REST 入口调用
python agents/mcp_client.py --rest --tool weather_forecast --args '{"city":"深圳","days":2}'
```

调用链会经过：**JWT 鉴权 → RBAC(role=admin) → Redis 限流 → 熔断放行 → 转发到 legacy-api → 成本计量 → 全链路审计**，并可在 Jaeger 里看到 trace。

## 7. 常用运维命令

```bash
docker compose logs -f gateway   # 网关日志
docker compose exec gateway sh -c './bin/ctl seed'   # 手动重建示例数据
docker compose down              # 停止（保留卷）
docker compose down -v           # 停止并清空数据库
```

## 8. 本地开发（不走 Docker）

需要：Go 1.22+、Node 18+、PostgreSQL、Redis、Python 3.10+。

```bash
# 1) 启服务
docker compose up -d postgres redis legacy-api mock-mcp
# 2) 网关（会连 docker 内 postgres，需映射端口）
cd gateway && go mod tidy && SEED_ON_STARTUP=true go run ./cmd/ctl serve
# 3) 前端
cd web && npm install && npm run dev
```

> 注意：本地直跑网关需在 `.env` 或环境变量里把 `DATABASE_URL`、`REDIS_ADDR`、`LEGACY_API_URL`、`MOCK_MCP_URL` 指到 `localhost` 端口（例如 `http://localhost:9002`）。

## 9. 故障排查

- **网关启动失败**：检查 `postgres`、`redis` 是否健康；`docker compose logs gateway`。
- **工具为空**：确认 `SEED_ON_STARTUP=true`，并在 `docker compose logs gateway` 查看 `seed-on-startup` 日志。
- **前端无数据**：确认浏览器能访问 `http://localhost:8080`（`VITE_API_BASE`）。
